translate.db update
===================

This patch checks for a newer Korean translate.db before OpenBatoru starts.

Files used by the launcher:

- LAUNCH_t.bat
- translate-updater.ps1
- translate-source.json

Default manifest:

https://raw.githubusercontent.com/andrew0416/open-batoru-translation-ko/main/translate-manifest.json

Default database download URL, provided by the manifest:

https://github.com/andrew0416/open-batoru-translation-ko/releases/latest/download/translate.db

How it works:

1. run.vbs starts LAUNCH_t.bat.
2. LAUNCH_t.bat runs translate-updater.ps1.
3. translate-updater.ps1 reads translate-source.json.
4. It downloads translate-manifest.json from GitHub.
5. If the manifest version or sha256 differs from the local state, it downloads
   translate.db.
6. The old local translate.db is backed up as translate.db.bak.
7. OpenBatoru.jar starts normally.

If the network is unavailable, the manifest is not ready, or the download fails,
the game still starts with the existing translate.db.

Changing language/source:

Edit translate-source.json and replace manifestUrl with another community's
manifest URL.
